# Боевая приёмка на ПК владельца

Этот чек-лист заполняется владельцем на установленном ПК под отдельной учётной записью `studlance`, с реальными CLI-сессиями и настоящими приложениями. До выполнения шагов весь статус — **не проверено**. Developer smoke, Go e2e и fakeagent проверяют кодовые пути, но не засчитываются как боевая приёмка. Не публикуйте задания, документы, вопросы, логи, снимки экрана с личными данными, token, cookies или CLI-сессиями.

Для каждой строки укажите дату и один статус: `не проверено` / `прошло` / `не прошло`. Доказательство обезличьте: достаточно общего статуса, типа приложения, времени и ссылок на синтетические/очищенные снимки без текста задания и содержимого работ.

## Журнал выполнения

Для каждого шага сохраните:

- номер шага и дату;
- выбранный статус;
- обезличенное доказательство и его локальное расположение;
- при `не прошло` — короткое точное описание наблюдаемого результата без файлов и секретов.

При сбое настоящего CLI сохраните только нужные владельцу закрытые логи. Перед отправкой отчёта проверьте и удалите из копии email, задания, имена файлов с персональными данными, local paths, cookies, session IDs, token и auth stores. Реальная приёмка считается завершённой только после выполнения всех пяти групп шагов с настоящими агентами на ПК владельца.
