# Макеты

Утверждённые макеты экранов в формате `.dc.html` (HTML с инлайн-стилями; значения цветов, отступов, размеров шрифтов брать отсюда буквально). Концепция и правила — в [../DESIGN.md](../DESIGN.md), что строить — в [../specs/](../specs/).

| Файл | Экран | Статус |
|---|---|---|
| `mockups/Main.dc.html` | Кабинет · новый заказ (`/new`) | **утверждён, делать точно по нему** |
| `mockups/KitWork.dc.html` | Кабинет · комплект в работе (`/orders/:id`) | ориентир по компоновке; содержимое листов — пример |
| `mockups/KitDone.dc.html` | Кабинет · комплект готов, замечание на листе | ориентир; метку-точку заменяет **выделение области** (как на этапе 4 в `Main`) |
| `mockups/AdminReview.dc.html` | Пульт · разбор заказа | ориентир |
| `mockups/PageTitle.dc.html`, `SheetCalc.dc.html`, `Drawing.dc.html` | листы-примеры для макетов выше | только для макетов, в продукт не идут |

Синтаксис `{{ … }}`, `<sc-if>`, `<sc-for>`, `<dc-import>` — шаблонизатор макетов; в React повторить результат, а не синтаксис. Анимации из `<helmet><style>` (`@keyframes sl-swipe`, `seg1…seg5`) переносятся как есть.
