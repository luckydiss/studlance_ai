# Studlance — дизайн

Статус: **концепция согласована**, макеты ключевых экранов — на дизайн-канвасе (приватный артефакт владельца проекта).

## Почему так

Конкуренты-генераторы (Кэмп, Экзамка, ИИ А24) выдают текст и сами называют его «черновиком, который нужно доработать»; расчёты, чертежи и код им не даются. Биржи (Автор24, Студворк) делают полный комплект, но через людей — дни и дорого. Наша позиция — **готовый проверенный комплект за часы**. Поэтому главный герой интерфейса — **сама работа**, а не чат и не статусы: клиент видит листы записки, таблицы расчёта и чертежи прямо на сайте.

## Концепция: «работа на столе»

- Светло-серая рабочая поверхность («стол»), на ней белые **листы** работы с мягкой тенью — как распечатки.
- Интерфейс вокруг почти без оформления: личность сайту дают сами документы.
- Листы — настоящие превью страниц (D20 в [ARCHITECTURE.md](ARCHITECTURE.md)), не схематичные заглушки.

## Основа

| | |
|---|---|
| Шрифт интерфейса | Golos Text |
| Шрифты внутри листов | как в реальных документах: PT Serif (записки), PT Sans (чертежи, таблицы), JetBrains Mono / PT Mono (код) |
| Стол | `#ECEDF0` |
| Текст / вторичный текст | `#15171A` / `#686C73` |
| Действия (кнопки, ссылки) | чернильно-синий `#1F3A93` |
| Замечания на листах | синяя прямоугольная рамка `#1F3A93`, 1.5 px, заливка `rgba(31,58,147,0.12)`, номер в углу рамки |
| Состояния | зелёный `#2B8A3E` — готово / исправлено, синий — идёт работа, жёлтый — ждём ответа клиента |
| Агенты в пульте | codex `#0F7B6C`, claude `#C2551F` |

Правила: один акцентный цвет для действий; цвет всегда несёт смысл; никаких декоративных карточек, «пилюль» и подписей капсом; служебная информация — только там, где она помогает.

## Кабинет клиента

1. **Новый заказ.** Вопрос «Что нужно сделать?», одно поле для запроса с файлами (в том числе папкой). Пример запроса без предмета: «Курсовая работа, вариант 14…».

   Ниже на столе — **«Любые работы — готовым комплектом»**: слева короткий текст (технические, гуманитарные, программирование; записка, расчёты, чертежи, код, презентация; замечание можно оставить прямо на листе), справа стопка из трёх крупных листов **реальных выполненных работ** разных типов, внахлёст и чуть повёрнутых: лист чертежа А3, страница записки со скриншотом запущенной программы, страница записки с таблицей и графиком. Подписей с предметами нет; под текстом — «Листы из выполненных работ, личные данные скрыты». Листы берутся из обезличенного набора `demo/` приватного репозитория.

   Ниже — **«Как это работает»**: строка из пяти шагов и под ней карусель, которая сама перелистывает этапы (по 4 секунды, по кругу; синяя черта под текущим шагом). Этапы: загрузили исходники → ИИ сделал работу → вы проверили → нужно — доработка (синяя рамка-замечание на листе и «Отправить на доработку») → готовая работа (версия 2, «Скачать всё»). Проверка нейросетью — внутренняя кухня, на сайте о ней не говорим. При `prefers-reduced-motion` карусель стоит на первом этапе.
2. **Комплект в работе.** На столе заготовки листов с названиями документов из `manifest.json` («Пояснительная записка · Word · 38 страниц»). В правом нижнем углу — **сворачиваемое окошко статуса** с шагами простыми словами.
3. **Комплект готов.** Слева документы с миниатюрами, в центре просмотр листов, сверху переключатель версий и «Скачать всё».
4. **Доработка.** Клиент выделяет место на листе синей прямоугольной рамкой `#1F3A93` (1.5 px, заливка `rgba(31,58,147,0.12)`, номер в углу) и пишет замечание. Справа список замечаний и «Отправить на доработку» → версия 2.
5. **Вопрос агента** приходит в окошко статуса и в карточку заказа; ответ — там же.

Слова для клиента: «заказ», «комплект», «версия», «доработка», «проверяем». Никаких «агентов», «генерации», «токенов».

## Пульт админа

**Разбор по листам**: слева трейс действий агентов по времени; в центре те же листы с переключателем «черновик codex / финал claude» и подсветкой изменённых мест; справа ведомость замечаний claude, каждое ведёт на лист. Выбор шага трейса или замечания показывает соответствующий лист. Шапка заказа и навигация — тёмные, чтобы пульт не путался с кабинетом.

## Что ещё нарисовать

Вход, «Мои заказы», вопрос агента, полноэкранный просмотр документа; в пульте — список заказов, клиенты, воркеры, метрики; мобильные версии кабинета.
