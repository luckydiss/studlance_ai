# План разработки MVP

Сразу делаем рабочий сайт с фронтендом по утверждённому макету: студент загружает задание и пишет запрос, воркер на ПК делает работу через codex и claude, готовый комплект появляется в кабинете, доработка по замечаниям на листах даёт новую версию. Отдельного этапа «проверки идеи» нет.

**Кто что делает:** код пишут агенты-разработчики по [спецификациям](specs/); спецификации и ревью каждого PR — на стороне проекта; приёмку на ПК с настоящими агентами делает владелец. Инструкция и текущее состояние для оркестратора (спеки, промпты, ревью, слияние) — [orchestration/README.md](orchestration/README.md).

**Как запускается:** два exe на ПК с Windows, без Docker — `studlance-server.exe` (API, сайт, SQLite, файлы в папке) и `studlance-worker.exe` (codex, claude, КОМПАС, Office). Хранилища — за интерфейсами, в проде меняются на Postgres и S3 ([ARCHITECTURE.md §15](ARCHITECTURE.md#15-горизонтальное-масштабирование-и-путь-в-прод)).

## Порядок работ

Подробно, с критериями приёмки, — [specs/09-tasks.md](specs/09-tasks.md).

| PR | Что | Спеки |
|---|---|---|
| 1 | Каркас: репозиторий, сборка, CI, SQLite и миграции, файлы, команды сервера, отдача фронтов | [01](specs/01-repo-build.md), [02](specs/02-data.md) |
| 2 | Контракт API, вход и сессии, заказы клиента, загрузка файлов, версии и архив, live (SSE) | [03](specs/03-lifecycle.md), [04](specs/04-api.md) |
| 3 | Очередь и API воркера: выдача, lease, heartbeat, fencing, авто-повтор, снимки, вопрос, finish | [03](specs/03-lifecycle.md), [04](specs/04-api.md) |
| 4 | Воркер: этапы, запуск codex и claude, разбор логов, промпты, снимки и превью листов, сравнение версий, доработки, Windows Job Objects, фейковые агенты | [05](specs/05-worker.md), [06](specs/06-prompts.md) |
| 5 | Кабинет: вход, новый заказ по макету, мои заказы, страница заказа (статус, вопрос, листы, версии, скачивание, доработка с выделением на листе) | [07](specs/07-web-client.md) |
| 6 | Пульт: заказы, разбор заказа (трейс live, черновик и финал с правками), клиенты, воркеры | [08](specs/08-web-admin.md) |
| 7 | Установка на ПК и боевая приёмка на настоящих работах | [01](specs/01-repo-build.md), [09](specs/09-tasks.md) |

PR 5 и 6 можно делать параллельно с PR 3–4: фронт опирается на контракт из PR 2.

## После MVP

Postgres и S3, docker compose для сервера, пул воркеров на VM, доступ к сайту извне, регистрация, оплата, уведомления.
